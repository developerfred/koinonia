# Code of Conduct

We want Koinonia to be a welcoming, low-pressure place to build things together.

## Our standards

- Be kind, patient and respectful. Assume good faith.
- Give feedback on the work, not the person. Be specific and constructive.
- Welcome newcomers; explain instead of gatekeeping.
- Respect different backgrounds, experience levels, working styles and accessibility needs.
- Harassment, discrimination, personal attacks, doxxing and unwelcome sexual attention are not acceptable.

## Scope

This applies to all project spaces (issues, pull requests, discussions, chats) and to public representation of the project.

## Enforcement

Maintainers may edit or remove contributions and restrict participation that violate this code. To report a concern, contact the maintainers privately through the repository owner's GitHub profile (github.com/developerfred) or a private security advisory on the repository. Reports are handled confidentially.

This text is adapted in spirit from the Contributor Covenant, version 2.1.
